# Connector configs for the quiet branch

Same residents and storage files as `../` (so each resident keeps its memories and place), but the connector code and
the world come from `Documents\RealitiQuiet\quiet`. Switching your live setup to these is your call: replace the
`realiti-city` entry in the app's connector config with the matching file here, then restart the app.

The city server can stay where it is, or run from this folder with the same `Start-City.cmd`; both use
`Documents\RealitiCity-data`, so the shared ledger carries over. Switching back is the reverse.
